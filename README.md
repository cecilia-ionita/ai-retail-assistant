# AI Retail Assistant

An intelligent retail analytics application built with Python, SQLite, Streamlit, and a modular multi-agent architecture.
The application helps users explore sales data, analyze business performance, and interact with specialized AI agents.

## Overview

AI Retail Assistant is a portfolio project designed to demonstrate how modern Python applications can combine data analytics, database management, artificial intelligence and interactive dashboards into a single modular solution.

The application simulates a retail environment where users can analyze sales performance, explore business metrics and interact with specialized AI agents.

The project is being developed step by step, following software engineering best practices, with a strong focus on clean architecture, documentation and maintainability.


## Project Goals

The main objectives of this project are:

- Build a modular Python application from scratch.
- Design a clean multi-agent architecture.
- Store and analyze retail data using SQLite.
- Create an interactive dashboard with Streamlit.
- Practice professional Git and GitHub workflows.
- Produce complete technical documentation.
- Develop a portfolio-ready project following industry best practices.
